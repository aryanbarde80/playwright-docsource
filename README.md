# Playwright Learning Lab

A complete, beginner-friendly path from JavaScript basics to a production Playwright automation framework.
Lessons are generated and maintained by Playwright Learning Lab.

**Progress:** 0 of 79 lessons published.

## Repository layout

- `roadmap/` — the full learning roadmap
- `phases/` — one folder per phase, one Markdown file per lesson
- `code-examples/` — code from each lesson
- `quizzes/` — knowledge checks
- `revision-notes/` — short revision notes
- `progress/` — publishing progress
